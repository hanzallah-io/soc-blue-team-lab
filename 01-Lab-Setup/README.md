\# 01 — Lab Setup



Initial multi-VM SOC lab build on VirtualBox with host-only networking.



\- Kali Linux — 192.168.56.102

\- Ubuntu Server (Wazuh Manager) — 192.168.56.10

\- Windows 10 — Wazuh agent endpoint



Includes VirtualBox networking configuration, base OS installs, and early

troubleshooting: VirtualBox/Hyper-V conflicts resolved via the WHP backend,

LVM volume extension after Wazuh installer disk space failures, and recovery

from filesystem corruption caused by RAM exhaustion.
