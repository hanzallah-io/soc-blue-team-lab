\# 04 — Network Segmentation



Introduced pfSense to convert the lab from a flat network into a segmented,

routed topology.



\- pfSense WAN/LAN interface configuration

\- All lab VMs repointed to pfSense as default gateway

\- Fixes for: 64-bit long mode boot failure (Hyper-V/VT-x conflict), kernel

&#x20; panic from disabled I/O APIC, and a WAN/LAN interface IP conflict that

&#x20; blocked the webConfigurator
